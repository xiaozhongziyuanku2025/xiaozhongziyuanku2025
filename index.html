Base64 文件名解码工具 - 使用教程

📖 什么是这个脚本？

你从本仓库下载的文件，文件名是 Base64 编码 的（比如 R1RYNjkwLWRyaXZlci5leGU=），解码后才是真正的文件名（如 GTX690-driver.exe）。

这个脚本会自动扫描目录下的所有文件，把 Base64 编码的文件名解码成原始名称，并自动处理重名冲突。

📝 常见问题

Q: 运行提示 base64: command not found

Git Bash 中可能没有 base64 命令，两种解决方法：

方法一：用 openssl 代替（Git Bash 自带）

打开脚本，把所有 base64 -d 替换为 openssl base64 -d

方法二：下载 base64.exe

从 https://github.com/kalbasit/base64/releases 下载，放到 C:\Program Files\Git\usr\bin\

Q: 运行提示 curl: command not found

  • Ubuntu/Debian：sudo apt install curl
  • macOS：brew install curl（需先安装 Homebrew）
  • Git Bash：curl 自带，如没有可手动下载脚本后放到目录

Q: 加速下载链接仍然很慢

公共代理稳定性有限，可以尝试换用其他代理前缀：

  • https://ghproxy.net/
  • https://gh-proxy.com/
  • https://hub.gitmirror.com/

Q: 中文文件名显示乱码

  • Git Bash：右键标题栏 → Options → Text → Character set 选择 UTF-8
  • Linux/macOS：运行 export LANG=zh_CN.UTF-8

Q: 无法切换盘符（C: / D:）

Git Bash 中盘符格式为 /c/、/d/：

cd /c/Users/Downloads   # 进入 C 盘
cd /d/                   # 进入 D 盘

运行脚本后输入 cd 也可以切换，例如输入 /d/病毒样本

Q: 下载脚本时中文文件名保存失败

可以重命名为英文后再下载：

curl -o decode.sh https://github.com/xiaozhongziyuanku2025/xiaozhongziyuanku2025/raw/main/小众资源库专用解码工具.sh
bash decode.sh

Q: 脚本无法执行，提示 Permission denied

chmod +x 小众资源库专用解码工具.sh
./小众资源库专用解码工具.sh

或者直接用 bash 运行，不需要执行权限：

bash 小众资源库专用解码工具.sh
