Base64 文件名解码工具 - 使用教程

📖 什么是这个脚本？

你从本仓库下载的文件，文件名是 Base64 编码 的（比如 R1RYNjkwLWRyaXZlci5leGU=），解码后才是真正的文件名（如 GTX690-driver.exe）。

这个脚本会自动扫描目录下的所有文件，把 Base64 编码的文件名解码成原始名称，并自动处理重名冲突。

📝 常见问题

Q: 运行提示 base64: command not found

Git Bash 中可能没有 base64 命令，两种解决方法：

方法一：用 openssl 代替（Git Bash 自带）

打开脚本，把所有 base64 -d 替换为 openssl base64 -d

方法二：下载 base64.exe

从 https://github.com/kalbasit/base64/releases 下载，放到 C:\Program Files\Git\usr\bin\

Q: 运行提示 curl: command not found

  • Ubuntu/Debian：sudo apt install curl
  • macOS：brew install curl（需先安装 Homebrew）
  • Git Bash：curl 自带，如没有可手动下载脚本后放到目录

Q: 加速下载链接仍然很慢

公共代理稳定性有限，可以尝试换用其他代理前缀：

  • https://ghproxy.net/
  • https://gh-proxy.com/
  • https://hub.gitmirror.com/

Q: 中文文件名显示乱码

  • Git Bash：右键标题栏 → Options → Text → Character set 选择 UTF-8
  • Linux/macOS：运行 export LANG=zh_CN.UTF-8

Q: 无法切换盘符（C: / D:）

Git Bash 中盘符格式为 /c/、/d/：

cd /c/Users/Downloads   # 进入 C 盘
cd /d/                   # 进入 D 盘

运行脚本后输入 cd 也可以切换，例如输入 /d/病毒样本

Q: 下载脚本时中文文件名保存失败

可以重命名为英文后再下载：

curl -o decode.sh https://github.com/xiaozhongziyuanku2025/xiaozhongziyuanku2025/raw/main/小众资源库专用解码工具.sh
bash decode.sh

Q: 脚本无法执行，提示 Permission denied

chmod +x 小众资源库专用解码工具.sh
./小众资源库专用解码工具.sh

或者直接用 bash 运行，不需要执行权限：

bash 小众资源库专用解码工具.sh

Aria2 联动下载 - 使用教程

📖 什么是 Aria2 联动？

本资源库支持将选中的文件“发送至 Aria2”进行多线程高速下载。Aria2 是一款轻量级的命令行下载工具，比浏览器自带下载快得多。

💡 注意：必须在电脑端后台运行 Aria2 并开启 RPC 服务，网页才能连上它。手机端如果不运行 Aria2，请直接使用网页自带的“下载”按钮。

🚀 第一步：启动 Aria2 (必须开启 RPC)

如果你下载的是 Aria2 的可执行文件，请打开命令行（CMD 或终端），输入以下命令启动：

aria2c --enable-rpc --rpc-listen-all=true --rpc-allow-origin-all

参数说明：

  • --enable-rpc：开启远程控制功能（必须）
  • --rpc-allow-origin-all：允许跨域请求（必须，否则网页连不上）

如果你设置了密码，启动命令需要加上：

aria2c --enable-rpc --rpc-allow-origin-all --rpc-secret=你的密码

⚙️ 第二步：在网页中配置

  1. 回到资源浏览页，点击左下角的 “小三点” 按钮，展开悬浮菜单。
  2. 点击 齿轮图标（本地设置）。
  3. 在弹出的设置面板中，确认 Aria2 RPC 链接（默认是 http://localhost:6800/jsonrpc）。
  4. 如果你在启动时设置了密码，请在 Aria2 RPC 密钥 中填入一模一样的密码。

📥 第三步：开始下载

  1. 点击左下角“小三点”，点击 多选模式。
  2. 勾选你想要下载的文件。
  3. 点击底部弹出的 “发至 Aria2” 按钮。如果提示“发送成功”，去 Aria2 的界面（或控制台）就能看到下载任务了。

⚠️ 常见报错解决

1. 提示“网络请求失败”或“被浏览器拦截”

原因：因为网页是 https:// 的安全连接，而你的 Aria2 是本地 http://，浏览器出于安全机制拦截了请求（混合内容拦截）。

解决方法：点击浏览器地址栏左侧的 “锁” 图标 → 点击 “网站设置” → 找到 “不安全内容”（Insecure content），将其改为 “允许”。刷新网页即可。

2. 提示“未授权”或“Token 错误”

原因：你在启动 Aria2 时加了 --rpc-secret，但网页设置里没填，或者填错了。

解决方法：检查网页设置中的密钥是否与启动命令中的密码完全一致。

3. 如何配置代理让 Aria2 下载更快？

Aria2 不走浏览器的代理。如果你在国内需要加速下载，可以在启动 Aria2 时加上代理参数（假设你有本地代理软件，端口为 7890）：

aria2c --enable-rpc --rpc-allow-origin-all --all-proxy=http://127.0.0.1:7890
